# Instagram provider

Install this package from the Cupboard and connect it in Settings → Integrations. It uses Instagram API with Facebook Login for Business, so the host holds the Facebook user grant and the package receives only `host.fetch`.

The package reads a bounded set of media and each media's newest comments. The API returns at most 50 comments per query and does not provide a replay cursor for older comments. When a full window cannot prove that the stored watermark is covered, the package returns `lossRisk` with the oldest reachable instant on its sync page. The host admits available comments and retains an incomplete-history warning on the source's health. Replies are expanded and become `ext:instagram:reply` records.

Instagram is media-primary: `social.post` refuses text-only and carousel requests, creates one media container, checks its status once per minute for at most five minutes, and publishes only after `FINISHED`. The package probes container status after an ambiguous publish and reports the observation without republishing. `social.reply` uses the comment replies edge and refuses hidden comments. `social.delete` verifies either a comment and its parent media or a media object, then requires that media's owner to match the configured professional account before deleting. Only an explicit missing-comment-field response permits the alternate media lookup; auth, throttle and other API failures propagate without retry. Permalinks are returned only when the server supplies them.

The package uses Graph API v26.0, matching Meta's [official Business SDK API version](https://github.com/facebook/facebook-python-business-sdk/blob/main/facebook_business/apiconfig.py). The generated [IGMedia](https://github.com/facebook/facebook-python-business-sdk/blob/main/facebook_business/adobjects/igmedia.py) and [IGComment](https://github.com/facebook/facebook-python-business-sdk/blob/main/facebook_business/adobjects/igcomment.py) expose DELETE at the object root. This establishes the request contract; actual grants and live media cleanup remain part of P-029 acceptance.

The newest-50 bound cannot recover older comments that fell out of the window. On a full cold page, or a full warm page that no longer reaches its watermark, the package reports incomplete history through the SDK loss contract. Later successful reads do not erase that warning. Comment edits and remote deletions are not discovered. Media outside the configured watch window is not polled; signed mention webhooks are handled separately.

Verification: recorded HTTP fakes and the shared provider conformance kit. **Live verification pending** on Avi's account (plan P-029).
# Mentions

Mentions arrive through Meta's signed `mentions` webhook. In the Meta app's Webhooks settings, use the connected source's public `/api/hooks/<source id>` URL and the verify token saved on Settings → Integrations. Subscribe the app to `mentions` and enable the linked Page's subscription using the required Page grant. The host verifies `X-Hub-Signature-256` with the existing Facebook OAuth app secret before handing the envelope to this package.

The package scopes each entry to the connected Instagram account, then retrieves the mentioned comment or caption with the IG User's `mentioned_comment.comment_id(...)` or `mentioned_media.media_id(...)` field. It does not poll a mentions collection. Private-account and Story mentions are unavailable under the vendor contract. Failed lookups leave the webhook unacknowledged so Meta can redeliver; normalized records use the regular connector admission and deduplication path. `social.reply` uses the stored mention's media id and, for a comment mention, its comment id with [POST /{ig-user-id}/mentions](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/mentions). The `social-instagram` pack offers separate disarmed bindings for comments, replies and mentions.

Primary contract: [Meta mention overview](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-facebook-login/mentions), [mentioned comment](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/mentioned_comment), [mentioned media](https://developers.facebook.com/documentation/instagram-platform/instagram-graph-api/reference/ig-user/mentioned_media), [webhook examples](https://developers.facebook.com/documentation/instagram-platform/webhooks/examples), and [signature and verification setup](https://developers.facebook.com/documentation/instagram-platform/webhooks).
